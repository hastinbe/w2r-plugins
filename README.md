# W2R plugins (downloads)

This repository only hosts the downloads for the plugins of the
[W2R Mod Loader](https://github.com/hastinbe/w2r-mod-loader-releases/releases) (Warcraft II Remastered):

- the plugin packages, as `pkg-<id>-<version>` releases;
- the plugin index (`index.json`) and manager update file on GitHub Pages, which the W2R Mod Loader reads.

You do not need anything here by hand: install and update plugins from the W2R Mod Loader.

The plugin source is not published here. To write your own plugin, see the public
[w2r-sdk](https://github.com/hastinbe/w2r-sdk) (plugin interface, manifest format and docs).
Plugins are MIT licensed (see `LICENSE`).
